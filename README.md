# 📚 Entendendo Algoritmos

> Códigos, anotações e implementações baseados no livro **"Entendendo Algoritmos"** de Aditya Y. Bhargava.

---

## 📖 Sobre o Livro

**Entendendo Algoritmos** é um guia ilustrado para programadores e curiosos, escrito por **Aditya Y. Bhargava**. Com uma abordagem visual e didática, o livro apresenta os principais algoritmos e estruturas de dados de forma acessível, sem abrir mão do rigor técnico.

O livro cobre desde conceitos fundamentais como busca binária até tópicos avançados como programação dinâmica e algoritmos de grafos — sempre com ilustrações, exemplos práticos e exercícios.

## 📊 Complexidade dos Algoritmos

| Algoritmo | Melhor caso | Caso médio | Pior caso | Espaço |
|-----------|:-----------:|:----------:|:---------:|:------:|
| Busca simples | O(1) | O(n) | O(n) | O(1) |
| Busca binária | O(1) | O(log n) | O(log n) | O(1) |
| Ordenação por seleção | O(n²) | O(n²) | O(n²) | O(1) |
| Quicksort | O(n log n) | O(n log n) | O(n²) | O(log n) |
| BFS | O(V + E) | O(V + E) | O(V + E) | O(V) |
| Dijkstra | O(E log V) | O(E log V) | O(E log V) | O(V) |
